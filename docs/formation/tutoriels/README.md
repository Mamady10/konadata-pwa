# Tutoriels vidéo KonaData

Des vidéos courtes (30 s à 1 min 15) qui montrent chaque geste du quotidien dans la vraie application : clics réels, zoom sur la zone utile, voix off française et sous-titres. Elles sont destinées aux utilisateurs des organisations clientes et aux partenaires qui les accompagnent (intégrateurs, formateurs, revendeurs).

Toutes les démonstrations sont tournées sur des **organisations vitrine** fictives (données inventées, aucun client réel) :

| Secteur | Organisation vitrine | Compte direction |
|---|---|---|
| BTP | Bâtir Guinée SARL | video.btp@konadata.demo |
| Écoles | Groupe Scolaire Horizon | video.ecole@konadata.demo |
| ONG | Santé & Avenir Guinée | video.ong@konadata.demo |
| PME | Espace Commercial Madina | video.pme@konadata.demo |

Mot de passe des comptes vitrine : `DemoKona2026!` (à ne communiquer qu’aux partenaires qui font des démonstrations).

## Diffusion aux partenaires

- **WhatsApp** : les vidéos font 3 à 11 Mo, elles s’envoient telles quelles. Envoyer une vidéo à la fois, au moment où la personne en a besoin (par exemple btp-03 le jour où le chef de chantier reçoit son accès).
- **YouTube (non répertorié)** : une playlist par secteur plus une playlist « Premiers pas » (tutoriels communs). Importer le fichier `.srt` comme sous-titres français.
- **Formations en présentiel** : projeter la vidéo, puis faire refaire le geste sur le compte vitrine du secteur.
- **Kit partenaire** : dossier partagé (Drive) contenant les vidéos du secteur, ce catalogue et les guides PDF de `docs/formation/`.

Les partenaires peuvent utiliser les comptes vitrine pour leurs démonstrations. Après une démonstration qui a créé des données, réinitialiser l’organisation (voir ci-dessous).

## Régénérer les vidéos

Les `.mp4` ne sont pas versionnés (trop lourds) : on les régénère à partir des scripts.

```powershell
# 1. (Re)créer les organisations vitrine — remet toutes les données à zéro
node scripts/tutorials/seed/seed-vitrine-btp.mjs
node scripts/tutorials/seed/seed-vitrine-ecole.mjs
node scripts/tutorials/seed/seed-vitrine-ong.mjs
node scripts/tutorials/seed/seed-vitrine-pme.mjs

# 2. Capturer (Playwright sur https://www.konadatagn.com) puis monter les tutoriels
node scripts/tutorials/build-tutorials.mjs                     # tout
node scripts/tutorials/build-tutorials.mjs --sector=btp        # un secteur (brand = tutoriels communs)
node scripts/tutorials/build-tutorials.mjs --only=btp-08-devis-metre
node scripts/tutorials/build-tutorials.mjs --list

# 3. Vidéos promo BTP (réutilisent les captures de btp-06 et btp-08)
node scripts/marketing/build-btp-promo-videos.mjs
```

- Les tutoriels sont décrits dans `scripts/tutorials/tutorials/<secteur>.mjs` (étapes, texte de la voix off, sous-titres). Chaque tutoriel nettoie ce qu’il crée : on peut le relancer sans réinitialiser l’organisation.
- Refaire les captures après chaque évolution visible de l’interface : la vidéo montre toujours l’écran réel au moment de la capture.
- Les dates des données vitrine sont calculées à partir du jour où l’on exécute le seed : relancer le seed le jour du tournage.
